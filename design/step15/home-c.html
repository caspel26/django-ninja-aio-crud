The whole API for one model

A Schemas class and a viewset register list, create, retrieve, update and delete under /api/articles/.

The same class is the CRUD API in plain Python: Article.create() or await Article.acreate().

Quickstart · Sync and async

blog/api.py 
class Article(ModelSerializer):
    title = models.CharField(max_length=200)
    is_published = models.BooleanField(default=False)

    class Schemas:
        create = SchemaConfig(fields=["title"])
        update = SchemaConfig(optionals=[("is_published", bool)])
        read = SchemaConfig(fields=["id", "title", "is_published"])


@api.viewset(model=Article)
class ArticleViewSet(APIViewSet):
    execution_mode = "sync"
    execution_mode = "async"  # the default
