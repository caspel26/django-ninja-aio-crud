3.0 Sync and async, one API →

The Django model is the API.

Declare which fields each operation reads and writes. django-ninja-aio-crud registers typed Django Ninja endpoints, validates every request and publishes the OpenAPI schema, served sync or async.

Get started
Hover a field to trace it through the request
blog/models.pyyou write
class Article(ModelSerializer):
    title = models.CharField(max_length=200)
    body = models.TextField()
    is_published = models.BooleanField(default=False)

    class Schemas:
        create = SchemaConfig(fields=["title", "body"])        update = SchemaConfig(optionals=[("is_published", bool)])        read = SchemaConfig(fields=["id", "title", "is_published"])

Everything around the endpoint.

Each capability is one attribute or mixin on the viewset, and each one works the same in sync and async mode.

Filtering and search query_params
Typed query parameters, checked against real model fields before they reach the ORM.
Pagination pagination_class
Page-number pagination by default. Swap in your own class per viewset.
Authentication AsyncJwtBearer
JWT bearer or HttpOnly cookie auth, set per verb with get_auth, post_auth and friends.
Permissions PermissionViewSetMixin
Object-level has_permission hooks, or role-based rules per operation.
Bulk operations bulk_operations
Create, update and delete many rows; each item succeeds or fails on its own.
Nested writes SchemaConfig(nested=…)
Create a parent and its reverse-FK children in a single transaction.
Soft delete SoftDeleteViewSetMixin
Mark rows deleted, restore them, or purge them for good.
AI agents manage.py mcp_server
Expose the same viewsets as MCP tools, with the same permissions.

Call it from Python, too.

The serializer is also the CRUD API for scripts, Celery tasks and tests. Sync and async are separate methods, never a flag, so type checkers see real return types.

Using serializers in Python
blog/tasks.py 
article = Article.create({"title": "Draft", "body": "..."})
article = Article.update(article, {"is_published": True})
data = Article.model_dump(article)
Article.destroy(article)
article = await Article.acreate({"title": "Draft", "body": "..."})
article = await Article.aupdate(article, {"is_published": True})
data = await Article.amodel_dump(article)
await Article.adestroy(article)
