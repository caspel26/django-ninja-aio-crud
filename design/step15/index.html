Step 15 · Visual directions

Three directions for the version 3 docsite, each shown as a homepage and the Declare schemas guide. All code, paths, responses and benchmark numbers match the version 3 API and comparison_results.json. Every page has a light and a dark theme (toggle in the header) and linked sync/async tabs.

DirectionCharacterTypePages
A · Manuscript Editorial. Serif display on warm paper, book-like measure, rules instead of boxes. Amber marks the one thing that matters on a screen. Source Serif 4, Source Sans 3, Source Code Pro Home · Guide
B · Console Technical. Visible 1px grid like a spec sheet, monospace indexes, no radii or shadows. Amber is the cursor: active tab, current page, this project's row. IBM Plex Sans, IBM Plex Mono Home · Guide
C · Index Reference-first. The homepage is an index built around search; dense, neutral, calm. Amber is reserved for attention: deprecations and version notices. Red Hat Display, Red Hat Text, Red Hat Mono Home · Guide

Notes

  • The guide page uses identical markup for all three directions; only the stylesheet changes (guide.html?d=a|b|c). This mirrors the real constraint: the theme's HTML is largely fixed, so a direction must be achievable mostly in CSS.
