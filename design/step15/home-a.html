Built on Django Ninja · Python 3.10–3.14

CRUD APIs for Django, from the models you already have.

Declare which fields each operation reads and writes. You get Django Ninja endpoints, request validation and an OpenAPI schema, served sync or async from the same class.

$ pip install django-ninja-aio-crud
Start the tutorial Five-minute quickstart
blog/models.py · blog/api.py 
class Article(ModelSerializer):
    title = models.CharField(max_length=200)
    body = models.TextField()
    is_published = models.BooleanField(default=False)

    class Schemas:
        create = SchemaConfig(fields=["title", "body"])
        update = SchemaConfig(optionals=[("is_published", bool)])
        read = SchemaConfig(fields=["id", "title", "is_published"])


api = NinjaAIO(title="Blog API")

@api.viewset(model=Article)
class ArticleViewSet(APIViewSet):
    execution_mode = "sync"
    execution_mode = "async"  # the default

One class, five endpoints

Paths come from the model's plural name. Omit a schema kind and its endpoint is not generated. Switching sync and async changes nothing on the wire.

Call it from Python, too

The serializer is also the CRUD API for scripts, Celery tasks and tests. Sync and async are separate methods, never a flag, so type checkers see real return types.

blog/tasks.py 
article = Article.create({"title": "Draft", "body": "..."})
article = Article.update(article, {"is_published": True})
data = Article.model_dump(article)
Article.destroy(article)
article = await Article.acreate({"title": "Draft", "body": "..."})
article = await Article.aupdate(article, {"is_published": True})
data = await Article.amodel_dump(article)
await Article.adestroy(article)

Measured, not claimed

Hand-written Django Ninja and FastAPI endpoints are faster on single objects; they also do less. ADRF is the slowest on every operation we measure.

Median milliseconds, 20–100 iterations each. Python 3.14, SQLite in memory, 26 September 2026. Reproduce with ./run-comparison.sh.
