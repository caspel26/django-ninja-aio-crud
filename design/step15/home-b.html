Quickstart Tutorial
01 · Model, viewset, request
blog/models.py
from django.db import models
from ninja_aio import ModelSerializer, SchemaConfig


class Article(ModelSerializer):
    title = models.CharField(max_length=200)
    body = models.TextField()
    is_published = models.BooleanField(default=False)

    class Schemas:
        create = SchemaConfig(fields=["title", "body"])
        update = SchemaConfig(
            optionals=[("is_published", bool)],
        )
        read = SchemaConfig(
            fields=["id", "title", "is_published"],
        )
blog/api.py
from ninja_aio import NinjaAIO, APIViewSet
from .models import Article

api = NinjaAIO(title="Blog API")


@api.viewset(model=Article)
class ArticleViewSet(APIViewSet):
    execution_mode = "sync"
    execution_mode = "async"
    # the default

02 · What one viewset registersOpenAPI tag: Article

Five routes, one schema per kind

Paths come from the model's plural name. Leave a schema kind out and its route is not registered. Sync and async produce the same paths, status codes and operation IDs.
