from ninja_aio import ModelSerializer, SchemaConfig


class Article(ModelSerializer):
    title = models.CharField(max_length=200)
    body = models.TextField()
    is_published = models.BooleanField(default=False)

    class Schemas:
        create = SchemaConfig(fields=["title", "body"])        update = SchemaConfig(optionals=[("is_published", bool)])        read = SchemaConfig(fields=["id", "title", "is_published"])


@api.viewset(model=Article)
class ArticleViewSet(APIViewSet):
    execution_mode = "sync"  # or "async"

Everything around the endpoint.

Each feature is one setting or mixin on the viewset, and works the same in sync and async mode.

Filtering and search query_params
Typed query parameters, checked against your model fields.
Pagination pagination_class
Page-number pagination by default. Swap in your own class per viewset.
Authentication AsyncJwtBearer
JWT bearer or HttpOnly cookie auth, set per method with get_auth, post_auth and friends.
Permissions PermissionViewSetMixin
Object-level permission checks, or role-based rules per operation.
Bulk operations bulk_operations
Create, update and delete many rows; each item succeeds or fails on its own.
Nested writes SchemaConfig(nested=...)
Create a parent and its children in a single request.
Soft delete SoftDeleteViewSetMixin
Mark rows as deleted, restore them, or remove them for good.
AI agents manage.py mcp_server
Expose the same viewsets as MCP tools, with the same permissions.

Call it from Python, too.

The same class is your CRUD API in scripts, Celery tasks and tests. Sync and async are separate methods.
